# FClaw Resources

Shared resources for FClaw skills on FlowOS.

This repository hosts downloadable assets and content used by FClaw skills, including wallpapers, images, media files, templates, and other shared resources.

## About

FClaw Resources serves as the centralized asset repository for the FClaw ecosystem.

Resources in this repository may be referenced by official and community-developed skills running on FlowOS-powered Foxx devices.

## Resource Categories

- Wallpapers
- Images and Icons
- Audio Assets
- Video Assets
- Templates
- Configuration Files
- Skill Content Packages

## Usage

Resources may be:

1. Downloaded directly by users
2. Referenced by FClaw skills
3. Distributed through skill packages
4. Updated independently from skill releases
